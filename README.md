# homebrew-tap

kanywst's Homebrew tap. Hosts the formulae and casks for CLI and TUI tools published from this account.

Everything here is generated by [GoReleaser](https://goreleaser.com/) from each upstream repository's release pipeline. Artifacts are:

- Cross-compiled for `darwin-{arm64,amd64}` and `linux-{arm64,amd64}`
- Bundled with a CycloneDX SBOM generated by [`syft`](https://github.com/anchore/syft)
- Checksum-signed (keyless) by [Sigstore `cosign`](https://www.sigstore.dev/) via GitHub OIDC, verifiable with the `.sig` and `.pem` published alongside each release

## Usage

```bash
brew tap kanywst/tap

# Formula
brew install kanywst/tap/spiffe-compliance-checker

# Cask
brew install --cask kanywst/tap/y509
```

## Verifying a release

Every upstream release publishes a checksum file plus a `cosign` keyless signature. To verify before installing:

```bash
TAG=v1.0.0
REPO=y509
gh release download "$TAG" -R "kanywst/$REPO" -p '*-checksums.txt*'

cosign verify-blob \
  --certificate "${REPO}-${TAG#v}-checksums.txt.pem" \
  --signature   "${REPO}-${TAG#v}-checksums.txt.sig" \
  --certificate-identity-regexp 'https://github.com/kanywst/.+/.github/workflows/release.yml@refs/tags/' \
  --certificate-oidc-issuer 'https://token.actions.githubusercontent.com' \
  "${REPO}-${TAG#v}-checksums.txt"
```

## How things land here

Each upstream repo's release workflow runs GoReleaser on `v*` tags, which commits the generated file to this repo using a `HOMEBREW_TAP_GITHUB_TOKEN` secret, a fine-grained PAT scoped to `contents: write` on this repository only.

Whether a tool lands in `Formula/` or `Casks/` is decided by the GoReleaser block the upstream repo uses: `brews` writes a formula, `homebrew_casks` writes a cask. It is not a CLI/GUI distinction. Everything published here is a terminal tool.
