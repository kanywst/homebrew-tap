# homebrew-tap

kanywst's Homebrew tap. Hosts the casks for CLI tools published from this account.

All casks are generated by [GoReleaser](https://goreleaser.com/) from each upstream repository's release pipeline. Artifacts are:

- Cross-compiled for `darwin-{arm64,amd64}` and `linux-{arm64,amd64}`
- Bundled with a CycloneDX SBOM generated by [`syft`](https://github.com/anchore/syft)
- Checksum-signed (keyless) by [Sigstore `cosign`](https://www.sigstore.dev/) via GitHub OIDC — verifiable with the `.sig` and `.pem` published alongside each release

## Usage

```bash
brew tap kanywst/tap
brew install --cask kanywst/tap/y509
```

## Available casks

| Name                                      | Description                                                            |
| ----------------------------------------- | ---------------------------------------------------------------------- |
| [`y509`](https://github.com/kanywst/y509) | TUI for inspecting X.509 certificate chains                            |
| [`brtc`](https://github.com/kanywst/brtc) | Cost calculator for offline password brute-force attacks (time + USD)  |

## Verifying a release

Every upstream release publishes a checksum file plus a `cosign` keyless signature. To verify before installing:

```bash
TAG=v0.8.1
REPO=y509
gh release download "$TAG" -R "kanywst/$REPO" -p '*-checksums.txt*'

cosign verify-blob \
  --certificate "${REPO}-${TAG#v}-checksums.txt.pem" \
  --signature   "${REPO}-${TAG#v}-checksums.txt.sig" \
  --certificate-identity-regexp 'https://github.com/kanywst/.+/.github/workflows/release.yml@refs/tags/' \
  --certificate-oidc-issuer 'https://token.actions.githubusercontent.com' \
  "${REPO}-${TAG#v}-checksums.txt"
```

## How casks land here

Each upstream repo's release workflow runs GoReleaser on `v*` tags. GoReleaser commits a `Casks/<name>.rb` to this repo using a `HOMEBREW_TAP_GITHUB_TOKEN` secret — a fine-grained PAT scoped to `contents: write` on this repository only.
